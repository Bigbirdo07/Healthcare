# Benefit Card Navigator — Portfolio Summary

## One-line description

Built a six-state public-data navigator that normalizes health-plan benefit information into searchable and comparable consumer-facing workflows with direct links to official evidence.

## Resume-ready description

- Developed a static health-benefit navigation platform covering 296 commercial plan records from 15 issuers across all six New England states, with detailed plan-level data for New Hampshire and Rhode Island.
- Built Python transformations that normalize public plan and benefit records into a browser-ready JSON model, and implemented plan search, benefit filtering, coverage explanations, and side-by-side comparison in JavaScript.
- Designed evidence links, missing-coverage warnings, and medical, insurance, and financial disclaimers so users can distinguish public information from authoritative coverage determinations.

## Technology

Python, JavaScript, HTML5, CSS3, JSON, public-data integration, responsive UI design, static deployment
